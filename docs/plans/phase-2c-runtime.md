# 2C：自主意图、调度与规则裁决

## 修改前判断

1. 问题：角色独立请求只更新私人认知，旧模拟仍由主角/NPC 管线代演动作；没有提交与裁决协议。
2. 优先级：P1 角色自主运行、P0 回合确定性与事实原子提交；不做 UI 美化。
3. 可验证收益：固定快照下各人物分别选择行动，世界裁判仅执行白名单规则，不读 CognitionStore、不调用 LLM、不编造台词或信念。严格牌局可确定结算至唯一幸存者。
4. 最小证明：mock 角色意图、事件日志重放、非法行动拒绝、已知/未知手牌可见性、失败重试、自由场景与严格轮转、旧用户数据兼容。

## 范围与边界

新运行时显式 opt-in；旧世界默认兼容模式，保存配置时可以选择独立运行。新模式在 RunDay 入口分流，不同时调用旧 EventGen/主角/NPC/WorldAdvance。世界设定仍可用原有创建工具；自身资料仅从明确定义的实体字段初始化，不复制整个世界书。

自由场景支持观察、等待、说话、移动和明确交互；严格场景先支持五人骗子酒馆式牌局，规则参数化但不声称支持所有桌游。牌局规则属于确定性裁判，不交给模型解释数值。

世界运行状态进入版本化 StateEngine，角色只提交结构化 Intent。一次回合收集的意图和裁决结果作为一个事件提交；失败调用不被当成等待或台词。成功 ThoughtReceipt 保存意图副本供同回合安全重试，正文推理不保存。

## 实现与验证（2026-10-22）

| 层次 | 文件 | 已实现行为 |
|---|---|---|
| 角色认知 | `agent.go`, `cognition.go`, `intent.go` | 独立输出认知和行动；行动引用本次可见来源；成功回合收据保存意图，重复请求复用；最新手牌帧和公开规则必须进入上下文，预算不足先报错 |
| 世界事实 | `scene.go`, `runtime.go`, `engine/state_engine.go` | 固定快照、两种调度、白名单动作、确定性裁决、原子日志、崩溃尾部恢复、非法牌局状态拒绝 |
| 认知传播 | `visibility.go` | 真实话语按明确受众传递；判定失败只反馈本人；已死亡人物不接收后续世界信息 |
| 集成 | `sim/independent.go`, `sim/narrative.go`, `main.go` | 显式 `execution_mode=independent` 替换旧行动管线；模型失败不伪装等待；后台失败停止、不自动重试/回档；不会因旧全局 LLM 指标误回档 |
| 操作台 | `world_agent_runtime.go`, `AgentSettingsPanel.svelte` | 保存模式；同室五人初始化，零模型请求，已有场景拒绝覆盖 |

严格牌局每轮仅唤醒当前人物；自由场景唤醒焦点地点中的相关人物。背景人物和 `on_direct_event` 只在初始回合或接到外部回执后唤醒；自己的等候/观察/失败反馈不触发下一轮。`on_involvement` 的参与范围目前是当前焦点场景。全局最多两个角色请求并发，另受档位、Provider 的更小上限约束。

五人协议使用 J/Q/K/A 牌组、隐藏出牌、声明、接受和质疑；扣命和重新发牌由程序执行；连续三次接受触发已公开的扣命规则，以限制无限接受。不是所有骗子酒馆变种或特权系统的实现。固定 seed 的 mock 角色仅依据自己的手牌与观察选择，五人都行动后产生唯一幸存者；日志重放等于最终快照。这里证明协议与隔离，不证明真实模型的博弈水平。

单次推进仍沿用旧 `Day` 字段作为兼容周期索引；独立小说明确把它解释为连续回合，不会要求跨越24小时。真实日历/分钟级时钟留待后续独立设计。

## 本阶段测试

- `runtime_test.go`：五人独立请求到唯一幸存者及重放、自由场景私话受众、失败重试、非法牌/过期意图/任意状态动作拒绝。
- `coordination_test.go`：档位并发、背景休眠、最新手牌必需上下文、已提交日志尾部恢复与不完整尾部保留。
- `sim/independent_test.go`：现有 RunDay 入口不再调用旧主角/NPC/世界模型；三次无变化后停止后续模型请求。
- `world_agent_runtime_test.go`：初始化零模型、不能覆盖、世界绑定、运行互斥、读取纯读；后台失败停止且完整牌局不因早期写作就绪而提前终止。

均使用临时目录和 mock，未迁移或运行用户已有世界，未调用付费 API。旧世界默认仍为兼容模式。
