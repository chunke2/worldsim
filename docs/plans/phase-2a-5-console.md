## 使用

进入“世界模拟”，点击操作台的 **API 服务 / 角色 Agent 设置**，或中央的 **角色 Agent** 标签。

1. 添加 API 服务：使用稳定英文 ID，填写 OpenAI 兼容 Base URL、本地密钥和显示名称。服务 ID 创建后不可修改。模型目录可逐行或逗号分隔；空目录允许手填，非空目录由服务端严格验证。
2. 保存服务。密钥留空保留，勾选明确清除才删除；更换地址需要新密钥或明确清除。高级 `extra_body` 留空保留，填写对象替换。公开读取不返回该对象或密钥。
3. 如需测试，填写已保存服务支持的模型，手动点击连接测试并确认。仅发一次短请求；进入页面、保存或刷新均不会自动测试。
4. 在当前世界配置核心人物、重要配角、背景人物三档模型。可展开预算与唤醒策略；0 表示使用运行时默认值。这里只保存策略，独立运行时还未接入。
5. 为每个人物选择重要性；需要时启用独立模型覆盖。未覆盖者始终跟随档位。休眠者保留身份与配置。
6. 保存三档与全部人物设置。运行中或旧版本请求会返回冲突，保留当前面板草稿；停止任务并等当前轮退出，或使用“重新读取”。重新读取会确认放弃未保存修改。离开标签或切换世界也会丢弃该面板草稿，密钥不写入浏览器存储。

“同步世界人物”是显式注册同步，不调用模型，也不创建小说人物；先初始化世界才会有人物实体。默认服务只影响后续派生配置，不批量重写已有档位或人物。

**目前旧模拟管线仍使用操作台原有模型配置。角色 Agent 设置完成不代表角色已经独立观察、记忆和决策；这属于 2B/2C。**

## 接口补充

世界 Agent 接口支持可选查询参数 `world=<encodeURIComponent(世界名)>`。服务端在操作开始时解析一次世界实例，比较目标名称与当前世界，不一致返回 409，且不写入任何配置或注册表。操作台总是携带该参数；旧客户端兼容原有不带参数的行为。

配置编辑不跟随 8 秒轮询重新载入，避免自动覆盖草稿。人物配置仍携带配置版本和注册表版本；Provider 使用全局配置指纹。冲突后不自动重试保存。

## 验证

以下全部通过，测试未访问真实模型或用户数据：

- `go test ./...`、`go build ./...`、`go vet ./...`。
- `node --test src/apps/world/lib/agentSettings.test.js`（在 `worldapp`，4 项）：空密钥/高级字段保留，显式清除，兼容 Provider 字段限制，模型覆盖继承，包含休眠人物的保存文档，Unicode 世界绑定与冲突。
- `npm run build`（在 `worldapp`）。有既有组件可访问性警告及大包提示，新 Agent 组件未产生编译警告。
- `node tests/agent-settings.browser.mjs`（在 `worldapp`）：所有 API 拦截为固定响应，验证五人设置、档位/独立覆盖提交、版本、休眠人物保留、409 草稿保留、密钥保存后清空、不进 localStorage/sessionStorage、无自动模型测试、显式测试一次、切换世界后目标正确。需要外部 Playwright；可设置 `PLAYWRIGHT_MODULE` 为其绝对模块路径，`BROWSER_CHANNEL=chrome` 或 `msedge` 使用本机浏览器。无需给项目安装生产依赖。

## 边界与下一项

配置页没有启用独立行动、模型路由、角色认知隔离或预算计量，也没有声称改善小说文学质量。没有重启现有服务或生成世界/小说。已运行的嵌入式二进制需要由用户选定时机重建并重启后才展示新页面。

2A-6 仍待单独验收：将固定五人注册、文件持久化、多 Provider 解析与凭据边界组合成完整集成场景，本次浏览器固定响应验证不替代该验收。
